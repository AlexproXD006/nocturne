Android

v1.0.55,3 MBAndroid 7+

¿Ya tenías Nocturne instalado? Desde la 1.0.5 la app usa la firma oficial, así que esta vez hay que desinstalar la versión anterior antes de instalar la nueva (solo una vez). Tu biblioteca, likes y playlists están en el servidor: no se pierden, solo tendrás que volver a iniciar sesión.

Descargar APK

Cómo instalar

  1. Si ya tenías Nocturne, desinstálalo primero (mantén pulsado el icono → Desinstalar). Solo hace falta esta vez.
  2. Descarga el APK con el botón.
  3. Android pedirá permitir instalar apps de orígenes desconocidos. Acéptalo.
  4. Pulsa Instalar y abre Nocturne.
  5. Pon el servidor de esta página e inicia sesión.

Windows

v1.0.0152 MB64-bit · portable
Descargar ZIP ¿Sin instalar? Descarga la versión portable (.exe)

Cómo usar

  1. Descarga y descomprime el ZIP en una carpeta.
  2. Entra en la carpeta y ejecuta Nocturne.exe.
  3. Windows SmartScreen puede avisar: pulsa Más información → Ejecutar de todas formas.
  4. Pon el servidor de esta página e inicia sesión.

Cómo instalar

  1. Descarga el instalador y ábrelo.
  2. Windows SmartScreen puede avisar: pulsa Más información → Ejecutar de todas formas.
  3. Elige la carpeta y termina la instalación. No requiere permisos de administrador.
  4. Pon el servidor de esta página e inicia sesión.
